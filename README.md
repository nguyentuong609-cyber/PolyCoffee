# PolyCoffee

A Java Web Coffee Shop Management System developed as a school project.

## Technologies Used

- Java
- Jakarta Servlet and JSP
- Hibernate / JPA
- SQL Server
- HTML, CSS, JavaScript
- Maven
- Apache Tomcat
- JUnit 5
- Selenium WebDriver

## Features

- User authentication and authorization
- Product and menu management
- Shopping cart
- Customer order management
- Barista order management
- Order status updates
- Automated testing with JUnit and Selenium

## Project Structure

- `src/main/java` - Java source code
- `src/main/webapp` - JSP pages, CSS, JavaScript, and images
- `src/test/java` - Automated test classes
- `pom.xml` - Maven project configuration

## How to Run

1. Clone this repository.
2. Import the project into Eclipse as an Existing Maven Project.
3. Configure your SQL Server database connection.
4. Run the database scripts if provided.
5. Configure Apache Tomcat 10.1.
6. Run the project on the Tomcat server.
